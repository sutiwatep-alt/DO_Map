# 💧 ระบบติดตามเครื่องวัด DO (DO Monitoring Map)

แผนที่ติดตามตำแหน่งเครื่องวัดออกซิเจนละลายน้ำ (Dissolved Oxygen) ของแต่ละฟาร์ม
- 🗺️ แผนที่ OpenStreetMap (ฟรี ไม่ต้องผูกบัตร)
- 🧭 นำทางในหน้าเว็บเลย (วาดเส้นทาง + ระยะทาง + เวลา) — ไม่เด้งออกไป Google Maps
- ➕ เพิ่ม/แก้/ลบหมุดได้จากหน้าเว็บ (คลิกแผนที่ / ใช้ GPS / พิมพ์พิกัด)
- ☁️ ซิงค์ข้ามเครื่องอัตโนมัติด้วย Firebase + ใช้งานได้แม้ออฟไลน์
- 📱 ติดตั้งเป็นแอปบนมือถือได้ (PWA)

---

## 📂 ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ + หน้าตา |
| `app.js` | ตรรกะทั้งหมด |
| `config.js` | **ไฟล์เดียวที่ต้องแก้** (ใส่ค่า Firebase / Google Key) |
| `sw.js` | ทำให้เปิดออฟไลน์ได้ |
| `manifest.json`, `icon*.png/svg` | ทำให้ติดตั้งเป็นแอปได้ |

> ตอนนี้เปิดได้เลยทันทีใน**โหมดเดโม** (เก็บข้อมูลในเครื่อง) เพื่อให้ลองก่อน — พอใส่ค่า Firebase แล้วจะกลายเป็นซิงค์ข้ามเครื่องอัตโนมัติ

---

## ▶️ 1) ทดลองรันในเครื่อง
```bash
cd GPS_Map
python3 -m http.server 8080
```
เปิด `http://localhost:8080` (ต้องเปิดผ่าน http นี้ ไม่ใช่ดับเบิลคลิกไฟล์ เพราะ GPS/ออฟไลน์ต้องการ http/https)

---

## ☁️ 2) เปิดซิงค์ข้ามเครื่อง (Firebase) — ครั้งเดียว ~10 นาที
1. ไปที่ https://console.firebase.google.com → **Add project** → ตั้งชื่อ (ปิด Google Analytics ก็ได้)
2. เมนูซ้าย **Build → Firestore Database → Create database**
   - เลือก **Start in production mode** → เลือก location `asia-southeast1` (สิงคโปร์ ใกล้ไทยสุด)
3. ไปแท็บ **Rules** วางกฎนี้แล้วกด **Publish**:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /stations/{doc} {
         allow read, write: if true;
       }
     }
   }
   ```
   > ⚠ กฎนี้ "ใครมีลิงก์ก็แก้ได้" เหมาะกับใช้ภายในทีม ถ้าต้องการล็อกให้เฉพาะคนล็อกอิน บอกผมเพิ่มระบบ Login ได้
4. กดรูปเฟือง ⚙ → **Project settings** → เลื่อนลงหัวข้อ **Your apps** → กดไอคอน `</>` (Web) → ตั้งชื่อ → **Register app**
5. จะเห็นโค้ด `const firebaseConfig = { ... }` → **คัดลอกค่าใน { } มาวางใน `config.js`** ให้ตรงช่อง:
   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "....",
     authDomain: "....firebaseapp.com",
     projectId: "....",
     storageBucket: "....appspot.com",
     messagingSenderId: "....",
     appId: "....",
   };
   ```
6. เซฟ แล้วรีเฟรชเว็บ → แถบ "เก็บในเครื่อง" จะเปลี่ยนเป็น **🟢 ซิงค์แล้ว** = ใช้ได้!

ข้อมูลทั้งหมดจะอยู่ใน Firestore (เปิดดู/แก้/ส่งออกได้ในหน้า Firebase Console → Firestore)

---

## 🌐 3) อัปขึ้น GitHub แล้วส่งลิงก์ให้คนอื่น (GitHub Pages)
1. สร้าง repo ใหม่บน https://github.com (เช่นชื่อ `do-monitor`)
2. อัปไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (ลากวางในหน้าเว็บ GitHub หรือใช้ git push)
3. ในหน้า repo → **Settings → Pages** → Source เลือก **Deploy from a branch** → Branch `main` / โฟลเดอร์ `/ (root)` → Save
4. รอสักครู่ จะได้ลิงก์ `https://<ชื่อคุณ>.github.io/do-monitor/` → **ส่งลิงก์นี้ให้ทุกเครื่องเปิดได้เลย**

> ได้ HTTPS ฟรี → GPS, นำทาง, และการติดตั้งเป็นแอปทำงานครบ

---

## 📱 4) ติดตั้งเป็นแอปบนมือถือ
เปิดลิงก์ GitHub Pages บนมือถือ → กดเมนูเบราว์เซอร์ → **เพิ่มไปยังหน้าจอโฮม / Add to Home Screen**
จะได้ไอคอนแอป เปิดได้เต็มจอ และ**ใช้งาน+เพิ่มหมุดได้แม้ไม่มีเน็ต** (พอกลับมามีเน็ตจะซิงค์เอง)

---

## 🧾 ข้อมูลแต่ละหมุด (กรอกจากปุ่ม ➕ เพิ่มหมุด)
ชื่อฟาร์ม • สถานที่ • พิกัด • สถานะ (ออนไลน์/ออฟไลน์/อัตโนมัติ) • ค่า DO ล่าสุด • เวลาอัปเดต • ติดต่อ • วันที่ติดตั้ง • รูป • หมายเหตุ

- **สถานะ "อัตโนมัติ"** = คำนวณจากเวลาอัปเดตค่า DO (เก่ากว่า 120 นาที = ออฟไลน์) ปรับได้ที่ `offlineThresholdMinutes` ใน `config.js`

---

## ⚙️ ตั้งค่าอื่น ๆ (ใน `config.js`)
- `mapCenter`, `mapZoom` — จุดกึ่งกลาง/ซูมแผนที่ตอนเปิด
- `googleApiKey` — ถ้าวันหน้าอยากเปลี่ยนพื้นแผนที่เป็น Google ก็ใส่ Key ที่นี่ (เว้นว่าง = ใช้ OpenStreetMap)

## ℹ️ ข้อควรรู้
- **การนำทางต้องมีเน็ต** (คำนวณเส้นทางจากเซิร์ฟเวอร์ OSRM) — ส่วนข้อมูลและการเพิ่มหมุดใช้ออฟไลน์ได้
- **ตอนออฟไลน์** ภาพพื้นแผนที่จะเห็นเฉพาะโซนที่เคยเปิดไว้ (ระบบแคชให้) ส่วนหมุดยังขึ้นครบ
- ถ้า 2 คนแก้จุดเดียวกันพร้อมกันตอนออฟไลน์ → ใช้กติกา "ใครบันทึกทีหลังชนะ"
